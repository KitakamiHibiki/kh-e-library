# kh e-library Android 客户端

自托管电子书库的 Android 客户端（功能与 Web 端对齐，见 [docs/Android客户端设计方案.md](../../docs/Android客户端设计方案.md)）。

## 功能

- ✅ **服务端根地址强制门槛**：未配置服务端根地址时 App 仅显示配置页，不允许进入任何功能；所有接口基于该根地址访问
- ✅ 书架：网格 / 关键字搜索（300ms 防抖）/ 状态筛选 / 排序（字段×升降序）/ 分页加载 / 阅读状态角标 / 处理中·失败遮罩
- ✅ 侧栏导航：全部图书 / 书架列表（每格数量）/ 未放入书架（`__none__`）/ 新建书架
- ✅ 卡片长按菜单：阅读 / 图书信息 / 标记在读·已读·未读 / 加入书架 / 重新解析 / 导出分享 / 删除
- ✅ 批量删除（长按进入多选模式）
- ✅ 图书详情：元数据 / 标签 / 简介 / 阅读入口 / 状态切换 / 加入书架 / 重新解析 / 导出分享 / 删除
- ✅ 标签管理：新建 / 重命名 / 删除；图书"加入书架"多选对话框（增删关联）
- ✅ 上传：文件选择器选 EPUB/PDF；≤20MB 直传，>20MB 分片上传（含进度）
- ✅ EPUB 阅读器：下载并解包、章节 WebView 渲染、目录跳转、字号调整、深色模式、进度自动保存与断点续读、阅读完成页
- ✅ PDF 阅读器：系统 `PdfRenderer` 渲染、翻页、页码跳转、捏合缩放、进度自动保存与断点续读、阅读完成页
- ✅ 统计概览（总数 / 未读 / 在读 / 已读 / 最近阅读）
- ✅ 运行时设置：读写服务端共享设置（主题 / 排序 / 每页数量 / 字号 / 阅读视图）
- ✅ 软件更新：检查更新 / 更新说明 / 下载并安装（二次确认）
- ✅ 中英文界面（`values/` + `values-en/`）

## 构建

工程使用 Gradle 8.10.2 + Kotlin 2.1 + AGP 8.7.3，compileSdk 35 / minSdk 26。

```bash
# 需先安装 JDK 17 与 Android SDK（本仓库开发机位于 D:\Android）
gradlew.bat assembleDebug    # 调试包
gradlew.bat assembleRelease  # 发布包（当前以 debug 签名，便于直接安装）
```

产物输出到 `app/build/outputs/apk/{debug,release}/`。

> 说明：本项目 `gradle.properties` 中已注释掉全局代理（原指向本地 Clash 127.0.0.1:7890，时常离线导致依赖下载失败），改为直连；如需要代理构建可自行恢复 `~/.gradle/gradle.properties.bak`。

## 连接自托管服务端

App 首次启动会强制进入"服务器设置"页，填写服务端根地址（如 `http://192.168.1.10:14325`）并「测试连接」，成功后进入书架。之后所有请求均基于该地址发起；书架右上角设置入口可随时修改。

## 已实现 / 与设计文档对照

首轮脚手架之后，已按 [设计方案](../../docs/Android客户端设计方案.md) P0 补齐：卡片操作菜单、批量删除、标签/书架管理、上传（含分片）、统计、运行时共享设置、软件更新、EPUB/PDF 阅读器与阅读完成页。阅读器采用"下载到本地缓存 + 原生渲染"：EPUB 章节 WebView 渲染（与 Web 端一致的阅读体验），PDF 使用系统 PdfRenderer（零外部依赖）。

> 已知取舍：PDF 阅读器暂为单页 + 捏合缩放（设计文档的双页/连续滚动视图可用运行时设置的值，本版以单页模式呈现）；阅读进度跨端（Android 与 Web）以 `progress` 字段为准，`cfi` 为 Android 私有定位格式。
